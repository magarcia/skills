# Upstream

This skill is based on
[Caidan Williams's `modern-css` skill](https://github.com/caidanw/skills/tree/main/modern-css),
which identifies [modern-css.com](https://modern-css.com/) as its source.

The local version:

- replaces the monolithic guide with a compact index and per-technique rule
  files;
- rewrites the workflow and production-readiness tiers;
- treats browser-support figures as snapshots;
- requires verification against the consuming project's browser policy and
  current primary documentation.
