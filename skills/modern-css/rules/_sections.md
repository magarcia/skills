# Sections

This file defines all sections, their ordering, support levels, and descriptions.
The section ID (in parentheses) is the filename prefix used to group rules.

---

## 1. Layout & Positioning (layout)

**Support:** 90%+
**Description:** Modern layout primitives that replace absolute positioning hacks, calc workarounds, and float-based designs.

## 2. Colors & Theming (color)

**Support:** 83-96%
**Description:** Perceptually uniform colors, wide gamut, dark mode, and dynamic color manipulation without preprocessors.

## 3. Typography & Fonts (typography)

**Support:** 79-96%
**Description:** Fluid sizing, text wrapping, font loading, and variable fonts that replace media query ladders and JS workarounds.

## 4. Selectors & Specificity (selector)

**Support:** 84-96%
**Description:** Modern selectors, native nesting, specificity control, and scoping that replace BEM, preprocessors, and !important.

## 5. Transitions & Animation (animation)

**Support:** 69-92%
**Description:** Entry animations, view transitions, scroll-linked animations, and animating to/from display:none without JS.

## 6. Interactive Components (component)

**Support:** 72-96%
**Description:** Native dialog, popover, anchor positioning, and customizable selects that replace JS libraries.

## 7. Performance & Rendering (performance)

**Support:** 90-96%
**Description:** Lazy rendering, scroll behavior, and image handling that replace IntersectionObserver and JS workarounds.

## 8. Forms (form)

**Support:** 73-93%
**Description:** Native form styling and validation that replace appearance:none hacks and JS blur handlers.

## 9. Experimental (experimental)

**Support:** < 70%
**Description:** Cutting-edge features with limited support. Use progressively or check project targets.
