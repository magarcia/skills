# Upstream

This skill is adapted from
[`obra/the-elements-of-style`](https://github.com/obra/the-elements-of-style).

The local `SKILL.md` expands the invocation triggers, condenses the wrapper,
makes loading the full reference explicit, and removes repeated summary
material. The bundled reference contains William Strunk Jr.'s public-domain
1918 text, which the upstream project sourced from
[Project Gutenberg #37134](https://www.gutenberg.org/ebooks/37134).

The upstream repository did not contain a separate software license when this
adaptation was reviewed.
